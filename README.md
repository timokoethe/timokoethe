I'm curious about frameworks, interfaces, and physical computing. My GitHub is a mix of Apple platform experiments, web projects, MicroPython hardware notes, and small tools that usually start with a simple question: *what happens if I build this?*

### Selected work

| Project | What it explores |
| --- | --- |
| [**Localight**](https://github.com/timokoethe/Localight) | Private, on-device conversations with Apple's Foundation Models on iOS. |
| [**Localframe**](https://github.com/timokoethe/Localframe) | Fully local image creation with Apple's Image Playground models. |
| [**CoreAIChat**](https://github.com/timokoethe/CoreAIChat) | A native macOS showcase for Apple's Core AI framework. |
| [**Pingo**](https://github.com/timokoethe/Pingo) | An open-source API scratchpad that lives in the macOS menu bar. |
| [**DropSweep**](https://github.com/timokoethe/DropSweep) | A tiny menu bar utility for keeping the Downloads folder clean. |
| [**NotificationManager**](https://github.com/timokoethe/NotificationManager) | A Swift package for scheduling and handling local notifications. |
| [**SX1278**](https://github.com/timokoethe/SX1278) | A MicroPython LoRa driver for Raspberry Pi Pico and Pico 2. |
