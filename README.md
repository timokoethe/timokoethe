### What I care about

- **Trying things early.** New frameworks, APIs, and devices only really click for me once I've used them.
- **Learning by building.** Prototypes and side projects are how I find out what actually works.
- **Mixing worlds.** Native apps, the web, on-device AI, and microcontrollers all end up on the same desk.
- **Writing it down.** I share what I learn, rough edges included, so others don't have to hit them twice.
